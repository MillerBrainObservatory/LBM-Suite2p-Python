# Notebooks

Rendering notebooks in documentation is less effective when the outputs of notebook cells is so dense.

For that reason, we render notebook contents in markdown with outputs we can control.

The notebooks here are kept on github for users to download, but may not be as up to date as the [usage guide](../usage/index.md) documentation, but contain the same (or similar) code cells.
